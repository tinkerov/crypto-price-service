
# Crypto Price Service

Backend-сервис для автоматического сбора курсов BTC/USD и ETH/USD из API Deribit с сохранением данных в PostgreSQL и предоставлением REST API для получения исторических и актуальных цен.

## Возможности

- Автоматический сбор цен BTC/USD и ETH/USD каждую минуту.
- Получение данных через публичный API Deribit.
- Сохранение цен и Unix timestamp в PostgreSQL.
- REST API для получения всех записей, последней цены и данных за конкретную дату.
- Выполнение фоновых задач с помощью Celery.
- Планирование периодического сбора данных через Celery Beat.
- Использование Redis в качестве брокера сообщений.
- Автоматизированные тесты на pytest.
- Запуск приложения и зависимостей через Docker Compose.

## Технологический стек

| Технология | Назначение |
|---|---|
| Python 3.12 | Основной язык разработки |
| FastAPI | REST API |
| SQLAlchemy | Работа с базой данных |
| PostgreSQL | Хранение данных |
| aiohttp | Асинхронные HTTP-запросы к Deribit |
| Celery | Выполнение фоновых задач |
| Celery Beat | Планирование задач |
| Redis | Брокер сообщений |
| pytest | Автоматизированное тестирование |
| Docker Compose | Запуск приложения в контейнерах |

## Design decisions

- **FastAPI** используется для создания REST API
  и автоматической генерации документации OpenAPI.

- **SQLAlchemy** используется для работы с PostgreSQL.
  Доступ к данным отделён от бизнес-логики с помощью
  репозитория.

- **Celery и Celery Beat** разделяют выполнение фоновых
  задач и их периодическое планирование.

- **Redis** используется в качестве брокера сообщений
  между Celery Beat и Celery Worker.

- **aiohttp** используется для асинхронных HTTP-запросов
  к публичному API Deribit.

- **Docker Compose** позволяет запускать приложение,
  базу данных и необходимые фоновые сервисы одной командой.

- **Unix timestamp** хранится в секундах, что упрощает
  сравнение временных меток и фильтрацию по датам.

## Быстрый запуск

### Требования

- Docker Desktop или Docker Engine
- Docker Compose

### Запуск приложения

```bash
docker compose up --build -d
```

После запуска интерактивная документация API будет доступна по адресу:

http://localhost:8000/docs

### Просмотр логов

```bash
docker compose logs -f beat worker
```

### Запуск тестов

```bash
pytest -v
```
